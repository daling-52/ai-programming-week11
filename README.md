# ai-programming-week11

## 데이터

- **출처**: AI 협업 프로그래밍 12주차 실습 배포 자료 (`scores_2026.csv`, 실습용 가상 성적 데이터)
- **행 수**: 원본 114행 5열 → 정제 후 100행 5열 (결측치 6행, 완전 중복 4행, 범위 밖 이상치 4행 제거)
- **열 설명**:
  - `학번` (문자): 학생 고유 번호
  - `이름` (문자): 학생 성명
  - `반` (문자): 소속 반 (`1반`, `2반`)
  - `과목` (문자): 응시 과목 (`수학`, `영어`, `프로그래밍`)
  - `점수` (정수): 과목 시험 성적 (0~100점)
- **빈 칸 처리 방법과 그 이유**: `점수` 열이 비어 있는(NaN) 6개 행은 `dropna(subset=["점수"])`를 사용해 삭제했습니다. 결측치를 0점이나 전체 평균으로 임의 대체하면 반별·과목별 실제 성적 평균이 왜곡되기 때문에, 유효한 성적 데이터만 남기기 위해 제거했습니다.
